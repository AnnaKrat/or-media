# or-media

Публичное хранилище **утверждённых** медиафайлов Operating Reality для публикации через Metricool.

- Сюда попадают только файлы со статусом APPROVED, готовые к публикации.
- Структура: `<Content ID>/<имя файла по конвенции OR>`, например `C016/OR_C016_LI_..._APPROVED.png`.
- Metricool скачивает файлы по ссылке `https://raw.githubusercontent.com/annakrat/or-media/main/<путь>`.
- Рабочие версии, черновики и исходники живут в закрытом репозитории `operating-reality`, не здесь.
